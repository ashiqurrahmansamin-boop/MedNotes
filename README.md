# MedNotes v2

A multi-page starter medical blog.

## Pages
- index.html — homepage
- articles.html — article library with category filters
- article-hypertension-kidney.html — first full article
- style.css — shared styling

## Publishing
This is a static website. You can upload the files to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host.

## Adding articles
Duplicate the article HTML file, change the title/content, and add a card linking to it from `articles.html`.

## Important
Verify medical claims against current authoritative guidelines and peer-reviewed literature before publishing. Do not include identifiable patient information. Educational content is not individualized medical advice.
